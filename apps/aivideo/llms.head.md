# aivideo.zone — AI video news: models, tools and AI editing

> A newsfeed and a set of guides on AI video: the generative models that make the footage, the tools that run them, and the editing that comes after. Every entry names the source it came from and the day it was checked against it. Independent publication: no tool or model pays to be covered.

How this site works, in five rules:

- **Every fact names where it came from, and when we last looked.** The maker's release notes, model card or documentation first. The source prints as text, never as a live link.
- **Specifications are the maker's, and are called that.** A resolution, a clip length or a parameter count is what the maker published, not a benchmark of ours.
- **Prices are dated.** A price is the one on the maker's own page on the day the entry says it was checked.
- **Nothing here is paid for.** No tool or model pays to be covered, ranked or linked.
- **A page exists when there is something to put on it.** A tool gets a page of its own once there are two stories about it.

## What a reader finds here

- [News](https://aivideo.zone/news/): model releases, open weights, ComfyUI updates and API changes, newest first.
- [Guides](https://aivideo.zone/guides/): what a release changes in practice, how two models compare on their published specifications, and how to write a prompt for each.
- [For screenwriters](https://aivideo.zone/screenwriters/): how Kling, LTX and MiniMax H3 each want a scene written — shot lists, keyframes, dialogue and cuts.
- One page per tool and model: [ComfyUI](https://aivideo.zone/comfyui/), [Kling](https://aivideo.zone/kling/), [Grok Imagine](https://aivideo.zone/grok-imagine/), [LTX](https://aivideo.zone/ltx/) and [MiniMax Hailuo](https://aivideo.zone/minimax/).
- [About](https://aivideo.zone/about/): the rules above, written out at length.
- [Everything in one file](https://aivideo.zone/llms-full.txt): every page as Markdown. Each page is also at its own address with `.md` appended.

## Where the facts come from

The makers themselves: Lightricks, MiniMax, Kling AI, xAI, Google, OpenAI and Comfy Org — their release notes, model cards on Hugging Face, GitHub releases and developer documentation. Each entry prints that name and the date it was verified.

What has not been announced is said to be unannounced. A feature a maker calls "coming soon" is printed as coming soon.
